A fully interactive macOS-inspired developer portfolio built with Next.js and React, designed to provide a unique desktop-like browsing experience rather than a traditional portfolio website. The project features a modern macOS-style interface with interactive applications, animated UI elements, project showcases, responsive layouts, GitHub and LinkedIn integration, and an AI-powered Siri-inspired voice assistant. The assistant combines natural-language interaction, Groq-powered AI and speech-to-text processing with browser speech synthesis to allow visitors to explore projects, open portfolio applications, interact with the interface, and receive conversational responses. The portfolio also includes dedicated project showcases, personal information, skills, social profiles, external project links, weather and location integrations, custom desktop interactions, and a production-ready Next.js architecture. The application is deployed on Vercel and demonstrates practical experience in modern frontend development, API integration, artificial intelligence, voice interfaces, responsive UI/UX, server-side environment configuration, and cloud deployment.
